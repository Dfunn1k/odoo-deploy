# Módulos locales

Los módulos que pongas aquí (una carpeta por módulo, cada una con `__manifest__.py`) se copian
dentro de la imagen y se incluyen automáticamente en el `addons_path`.

Úsalo solo para módulos propios de este cliente que no tengan repo. Lo normal es tener los módulos
en un repo git y declararlo en `../repos.txt`.
